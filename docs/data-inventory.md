# Data inventory

Every kind of data the service stores, who can see it, how long it is kept, what happens to it when an account is deleted, whether it is in the export a user can download, and which outside party receives it. A test in `packages/db` fails when a table, a storage location or an outside host is missing from this file.

## Classes

| Class          | Meaning                                                               |
| -------------- | --------------------------------------------------------------------- |
| `public-civic` | Civic data from public sources                                        |
| `public`       | Content or profile fields a user published                            |
| `private`      | Data about one user that only that user sees                          |
| `sensitive`    | Private data that reveals political opinion or where someone lives    |
| `restricted`   | Direct messages, report evidence and material kept under a legal hold |
| `secret`       | Credentials and bearer values, stored only as hashes or ciphertext    |
| `pseudonymous` | Keyed hashes that stand in for a person                               |
| `operational`  | Counters, health rows and logs of events with no free text            |
